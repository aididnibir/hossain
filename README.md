## PROMPT START

Build a premium, one-page portfolio website for a Senior Talent Acquisition / HR professional named **Hossain Ucchas** (also goes by "Wahid"). This site needs to feel like a boutique recruitment consultancy, not a generic resume page — warm, credible, human, and quietly confident. Avoid corporate-blue cliché HR site vibes.

### 1. BRAND & COLOR SYSTEM (soft, professional, distinctive)

Use a "Sage & Clay" palette — muted, warm, and unusual for the HR/recruiting space (most competitors use navy/electric blue, so this should feel differentiated):

- **Ink Navy** `#20293A` — primary text, headers, nav background
- **Sage** `#8FA98F` — primary accent (buttons hover states, section dividers, icons)
- **Deep Sage** `#5F7A66` — secondary accent, links, active states
- **Warm Sand** `#F4EFE6` — main background (soft, not stark white)
- **Cream** `#FBF8F2` — card backgrounds, alternating section backgrounds
- **Clay/Terracotta** `#C6785A` — CTA buttons, highlight underlines, key stat numbers (used sparingly, as the "pop" color)
- **Charcoal Grey** `#4A4F55` — body text on light backgrounds
- **Hairline** `#DED6C7` — borders, dividers

Typography: a refined serif for headlines (e.g. "Fraunces", "Source Serif 4", or "Lora") paired with a clean humanist sans for body/UI (e.g. "Inter" or "Public Sans"). Generous whitespace, soft rounded corners (12–16px), subtle shadows (never harsh), soft fade/slide-in scroll animations. No neon gradients, no glassmorphism clichés — feel editorial and calm.

### 3. INTERACTIONS & POLISH
- Sticky nav with active-section highlighting, background blurs to cream on scroll
- Scroll-triggered fade/slide-up animations on each section (subtle, 400–600ms ease)
- Smooth anchor scrolling for nav links
- Fully responsive: stacked single-column layout on mobile, timeline collapses to a simple vertical list with left border accent
- Skill pills wrap naturally on mobile
- Buttons have soft hover lift (translateY -2px) and color transitions, no harsh drop shadows
- Use accessible color contrast (Ink Navy text on Sand/Cream backgrounds passes WCAG AA)

### 4. TONE OF VOICE FOR ANY COPY YOU GENERATE
Confident, warm, precise — like an experienced recruiter who respects people's time. No corporate jargon, no buzzword soup. Short sentences. Avoid "passionate," "results-driven," "synergy," "rockstar."
